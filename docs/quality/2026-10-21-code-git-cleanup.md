## Исправленные дефекты

1. **PageSpeed возвращал 502 для URL с query/fragment.** Публичные URL ответа теперь проходят ту же редактирующую функцию, которую ожидает frontend-контракт. Провайдер по-прежнему получает полный проверяемый адрес. Регрессионный тест проверяет обе границы.
2. **Дополнительные проверки теряли query исходной страницы.** Ссылки из результатов аудита теперь используют введённый пользователем адрес, а не публичный адрес из backend-отчёта, в котором параметры намеренно скрыты. Браузерный тест проверяет адрес вида `/?p=42` для PageSpeed и проверки метатегов.
3. **Копирование показывало успех при отказе Clipboard API.** Запись ожидается через общий helper; успех появляется после разрешения Promise, отказ обрабатывается локализованной ошибкой без необработанного исключения. Проверены копирование ссылки и фрагмента.
4. **Карточка метрики показывала порог провала для статуса warning.** Отдельный компонент различает pass, warning, fail и unavailable. При отсутствии данных показано нейтральное состояние без выдуманного значения и рекомендации. Исправлен ключ полевой метрики INP.

Четыре исправления дополнительно проверены независимым read-only reviewer: замечаний P1/P2 в этом объёме не найдено. Проверка не распространялась на весь продукт и не включала живые вызовы провайдеров.
