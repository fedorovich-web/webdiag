## Воспроизведённые дефекты и исправления

| Дефект | Причина | Исправление и подтверждение |
|---|---|---|
| После перехода из hero или нижней формы адрес теряется | Состояние инициализировалось из `window.location` во время рендера; effect выполнялся только при первом mount | Реактивный `useSearchParams`, Suspense и отдельный экземпляр workbench на каждый адрес. Браузерные сценарии RU/EN проверяют адрес и ровно один POST |

| Переход к PageSpeed снова требует вводить адрес | Инструмент игнорировал `?url` и использовал пример `example.com` | PageSpeed принимает адрес из отчёта и запускается автоматически; проверено в браузере |
| Статус показывал выполненные DNS/SSL/PageSpeed этапы без серверных событий | Прогресс генерировался таймером | Удалены проценты и фиктивное завершение этапов; показывается ожидание результата сервера |
| В отчёте всегда отображались хорошие LCP/CLS/INP/FCP | Значения были записаны прямо в JSX; преобразователь API отбрасывал evidence | Сохранение и валидация evidence, реальные идентификаторы метрик backend, отдельные подписи lab/field, отсутствие данных показано явно |
| Неполная статическая проверка страницы | Не проверялись восемь важных групп сигналов | Добавлены X-Robots-Tag, HTTPS, viewport, lang, alt, размеры изображений в HTML, последовательность заголовков и повторяющиеся метатеги |
| Ошибочная индексация | `none` игнорировался, проверка подстроки давала ложные noindex | Разбор директив по токенам и отдельный разбор заголовков с префиксом user-agent; общий механизм используется и инструментом indexability |
| SVG и шаблоны создавали ложные SEO-ошибки | SVG title считался title документа, содержимое template — изображениями и заголовками страницы | Исключены SVG и инертные вложенные template; отдельный регрессионный HTML fixture |
| Длинный title/H1 или повреждённый canonical обрывал весь отчёт | Непроверенные строки попадали в ограниченные модели; URL parser выбрасывал исключение | Ограничены образцы evidence с отметкой об усечении, ошибочный canonical становится замечанием в отчёте |
| JSON и другие не-HTML ответы получали ошибки о пропущенных HTML-тегах | HTML-проверки выполнялись независимо от MIME-типа | HTML-проверки помечаются skipped, соответствующие ложные issues исключаются |
| Недоступный robots.txt считался пройденной проверкой | Отсутствие найденного запрета приравнивалось к успешному анализу | Недоступность показана как skipped |
| Timeout/503 sitemap выдавался за отсутствие файла | Любая ошибка загрузки превращалась в missing | Missing только для 404/410; неподтверждённая доступность — skipped |
| Контекст AI искажал слова и FAQ | HTML text nodes соединялись пробелами без учёта inline/block семантики | Inline-фрагменты сохраняют слова; блочные элементы, включая details/summary, разделены; скрытый служебный контент исключён |
| Страница обещала Chromium, 65+ факторов и результат за три секунды | Текст не соответствовал исполняемому пути | Описание приведено к статическому HTML, 22 группам проверок и условной доступности PageSpeed; удалены выдуманные гарантии |

Удалены недостижимая preview-ветка домашней формы и оставшиеся только от неё CSS-правила, а также скрытая legacy-разметка прогресса. Адреса со встроенными логином/паролем отклоняются до перехода на страницу аудита.

Восемь новых групп не выполняют дополнительных сетевых запросов. Отсутствие width/height в HTML является замечанием о статической разметке, а не доказанным CLS: рекомендация допускает CSS aspect-ratio и требует проверки в браузере. Новые проверки и замечания включены в общую taxonomy, scoring и локализацию RU/EN, включая сохранённые отчёты.
