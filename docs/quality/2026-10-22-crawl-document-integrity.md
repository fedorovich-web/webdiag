## Robots.txt и sitemap

При транспортной ошибке robots.txt обход раньше продолжался, как будто запретов нет. Ответы 5xx также не препятствовали загрузке sitemap и страниц. Теперь такие задачи завершаются со стабильным `crawl_robots_unavailable` до последующих HTTP-запросов. Код проходит через сохранение состояния задачи, а кабинет RU/EN объясняет остановку.

Отсутствующий файл с HTTP 404 и сетевая ошибка различаются. Продолжение обхода при 4xx и остановка при сетевой ошибке/5xx соответствуют [RFC 9309, разделы 2.3.1.3–2.3.1.4](https://www.rfc-editor.org/rfc/rfc9309.html#section-2.3.1.3). Это исправление конкретной обработки ошибок, а не заявление о полной реализации всех требований RFC.

Правила robots теперь проверяются перед запросом sitemap, дочерних карт и переходом по редиректу sitemap. Локальные тесты через настоящий `SafeHttpFetcher` и `httpx.MockTransport` подтверждают, что запрещённый адрес не запрашивается. Неполный sitemap не создаёт утверждений об отсутствии внутренних ссылок.

В 16 прежних fixtures обычное отсутствие robots было представлено `SafeFetchError`. Они заменены на явный HTTP 404; проверки бюджета, редиректов, query, обхода и sitemap сохранены. Транспортные ошибки отдельно проверяются новыми тестами с запретом любых дальнейших запросов.

## Активные и инертные ссылки

Ссылки внутри вложенных template больше не участвуют в графе сайта и не расходуют лимит 500 ссылок страницы. Это предотвращает пропуск настоящих ссылок после большого шаблона и ложное исчезновение кандидатов без внутренних ссылок.

Ревью воспроизвело отдельный случай `<template/>`: стандартный Python HTMLParser немедленно вызывал закрытие элемента, хотя в HTML такой slash не закрывает template. Общий `TemplateAwareHTMLParser` устраняет это поведение в четырёх парсерах: метаданных, полного обхода, ссылок и изображений. Контрпример с 501 инертной ссылкой теперь сохраняет активную ссылку после template и не исчерпывает бюджет. Содержимое template не учитывается как title, изображение или ссылка в отдельных инструментах. Основание для поведения — [HTML Standard: template](https://html.spec.whatwg.org/multipage/scripting.html#the-template-element). Полная эквивалентность парсера браузерному DOM не заявляется.

Другой воспроизведённый случай — `<a href="" href="/invented">`. Обход выбирал второй непустой атрибут и запрашивал выдуманный переход. Теперь используется первый href, включая пустой или valueless; пустой адрес разрешается относительно базы документа. Два теста с `<base href="/section">` подтверждают загрузку `/section` и отсутствие запроса `/invented`.

## Длинные метаданные

Title длиннее 300 символов или description длиннее 500 не помещались в модель страницы. ValidationError обрывал задачу до нормального сохранения результата. Теперь в результат попадает образец с `… [truncated]`, а аудит самой страницы получает исходный HTML.

Дубли определяются до усечения: для полного casefold-значения вычисляется SHA-256, в накопителе хранятся digest, ограниченный образец и URL. Таким образом, не накапливаются полные мегабайтные строки всех страниц. Одинаковые начала с разными окончаниями не объединяются; одинаковые полные значения сохраняют группу дублей. Регрессии проверяют title и description на трёх страницах, а reviewer дополнительно проверил значения по миллиону символов.
