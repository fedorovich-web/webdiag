# Финальная приёмка WebDiag — 23 октября 2026

База: `d2bde2a` (`main` после PR #58). Сохранённые рабочие копии backend не переключались и не изменялись; переносились только воспроизведённые исправления по действующим контрактам.

## Исправлено

- Повреждённая ссылка в sitemap после корректной корневой записи больше не обрывает обход. Карта отмечается неполной, корректные страницы продолжают проверяться.
- Количества страниц с дублирующимися метаданными и кандидатов без внутренних ссылок рассчитываются до ограничения примеров в ответе. Ограниченные списки больше не уменьшают полные количества.
- Сохранённые AI-результаты проверяются по контрольной сумме, состоянию и форме JSON. Повреждённые результаты возвращают контролируемую ошибку с `Cache-Control: no-store`.
- Вход AI-задачи проверяется до изменения состояния и создания попытки: повреждённые данные не выдаются провайдеру. Целостность транзакции проверена регрессиями.
- Сохранённые аудиты отклоняют повторяющиеся JSON-ключи, недопустимые числа и строки, которые невозможно передать в UTF-8. Корректные пары Unicode остаются допустимыми.
- Worker отклоняет неоднозначный JSON и логический флаг вместо количества обработанных задач. Ошибочные тайм-ауты не заменяются молча ближайшим допустимым значением.
- Генераторы robots.txt, sitemap.xml и FAQPage проверяют входные данные, не отбрасывают неполные пары вопрос/ответ, безопасно формируют script-элемент JSON-LD и показывают ошибки на выбранном языке. Демонстрационные значения перенесены в placeholder; конфигурационное значение User-agent `*` сохранено.
- Sitemap priority проверяется как десятичное значение XML в диапазоне 0–1; шестнадцатеричная и экспоненциальная запись не попадают в XML.
